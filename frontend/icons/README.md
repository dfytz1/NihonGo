Place **icon-192.png** and **icon-512.png** here for PWA install prompts.

Quick option: export two square PNGs from any design tool, or use
[RealFaviconGenerator](https://realfavicongenerator.net/) with the SVG favicon from `index.html`.

For “Add to Home Screen” on iOS, also add **apple-touch-icon** (180×180) if you want a custom home screen icon; reference it in `index.html`.
